# JHP

메이플스토리 재획비 타이머 + OTT 시청 보조 도구

## 다운로드
→ [Releases 페이지](https://github.com/dlrj0/JHP/releases)에서 최신 버전 다운로드 (Release가 아직 없으면 저장소를 직접 빌드하세요: `dotnet build JHP/JHP.csproj`)

## 설치 방법
1. zip 압축 해제
2. alarm 폴더에 알람용 mp3 파일 추가
3. JHP.exe 실행

## 주요 기능
- 재획비 타이머 8슬롯 (2시간/1시간/30분/20분/15분/10분/100초/55초)
- 커스텀 알람 3슬롯
- 내장 브라우저 (WebView2)
- mp3 알람 / TTS 음성 안내
- 사이트 즐겨찾기
- 넷플릭스 오프닝 건너뛰기/다음 화 자동 클릭
- 항상 위 / 투명도 조절
- 포커스 아웃 시 테두리 숨김
- 새 버전 알림 (GitHub Releases에서 확인 후 다운로드 페이지 열기)

## 사용 환경
- Windows 10 / 11 64bit
- Microsoft Edge WebView2 런타임 필요 (Windows 10/11에는 대부분 이미 설치되어 있음)

## 주의사항
본 프로그램은 넥슨의 공식 허가를 받은 프로그램이 아닙니다.
사용으로 발생하는 모든 불이익에 대한 책임은 사용자 본인에게 있습니다.

## 사용법
- 타이머 버튼: 좌클릭으로 시작/정지, 우클릭으로 알람 설정창 열기/닫기 (마우스를 올리면 다음 알람 시각 표시)
- ▼ 버튼: 사이트 이동/추가/삭제(✕), 항상 위, 다른 창 선택 시 테두리 숨기기, 알람 울릴 때 영상 음소거, 설정 내보내기/가져오기
- 사이트 항목을 우클릭하면 위/아래 이동, 이름/주소 수정, 시작 사이트 지정을 할 수 있습니다.
- 이미 실행 중일 때 다시 실행하면 새로 띄우지 않고 기존 창을 앞으로 가져옵니다.
- 설정 내보내기/가져오기로 사이트 목록과 알람 설정을 json 파일로 백업·복원할 수 있습니다.
- 볼륨/투명도 숫자를 클릭하면 직접 입력할 수 있습니다 (입력하는 즉시 반영, Esc로 취소)
- 알람 소리는 `alarm` 폴더의 mp3 파일명을 선택합니다 (기본 이름 `경험치업.mp3`, 없으면 시스템 소리로 대체)
- 설정은 exe와 같은 폴더의 `config.json`에 저장되며, 문제가 생기면 같은 폴더의 `error.log`를 확인하세요(exe 폴더에 쓸 수 없고 기존 `config.json`이 없으면 설정·캐시·로그를 `%LOCALAPPDATA%\JHP`에 둡니다).
- 전역 단축키(▼ 메뉴에서 켜기, 기본 꺼짐): Ctrl+Alt+Shift+F10 = 타이머 시작/정지 (게임 조작 키와 겹치지 않는 조합)
- 타이틀바 빈 영역을 더블클릭하면 최대화/이전 크기, 링크로 열리는 새 창은 같은 창에서 열립니다.
- 노트북을 덮는 등 2분 넘게 멈췄다 돌아오면 알람 시간은 그 시점부터 다시 셉니다.
- 전체화면(독점) 모드에서는 '항상 위' 창이 보이지 않을 수 있으니 창 모드 또는 전체 창 모드(테두리 없는 창)를 권장합니다.

## 안전/개인정보
- 이 프로그램은 게임 프로세스를 읽거나 조작하지 않습니다(메모리 접근, 키 입력 합성, 키 후킹, 화면 캡처 없음). 독립된 보조 창입니다.
- 배포용으로 폴더를 압축할 때 `cache/`(웹 로그인 정보)와 `config.json`(최근 주소, 사이트 목록)은 제외하세요.
