# JHP

메이플스토리 재획비 타이머 + OTT 시청 보조 도구

## 다운로드
→ [Releases 페이지](https://github.com/dlrj0/JHP/releases)에서 최신 버전 다운로드 (Release가 아직 없으면 저장소를 직접 빌드하세요: `dotnet build JHP/JHP.csproj`)

## 설치 방법
1. zip 압축 해제
2. alarm 폴더에 알람용 mp3 파일 추가
3. JHP.exe 실행

## 주요 기능
- 재획비 타이머 8슬롯 (2시간/1시간/30분/20분/15분/10분/100초/55초)
- 커스텀 알람 3슬롯
- 내장 브라우저 (WebView2)
- mp3 알람 / TTS 음성 안내
- 사이트 즐겨찾기
- OTT 다음화 자동 스킵 (라프텔, 넷플릭스 — 페이지 로드 시 1회 시도, 개선 예정)
- 항상 위 / 투명도 조절
- 포커스 아웃 시 테두리 숨김
- 자동 업데이트 확인 (GitHub Releases)

## 사용 환경
- Windows 10 / 11 64bit
- Microsoft Edge 설치 필요 (대부분 이미 설치됨)

## 주의사항
본 프로그램은 넥슨의 공식 허가를 받은 프로그램이 아닙니다.
사용으로 발생하는 모든 불이익에 대한 책임은 사용자 본인에게 있습니다.

## 사용법
- 타이머 버튼: 좌클릭으로 시작/정지, 우클릭으로 알람 설정창 열기/닫기 (마우스를 올리면 다음 알람 시각 표시)
- ▼ 버튼: 사이트 이동/추가/삭제(✕), 항상 위, 다른 창 선택 시 테두리 숨기기, 알람 울릴 때 영상 음소거, 설정 내보내기/가져오기
- 사이트 항목을 우클릭하면 위/아래 이동, 이름/주소 수정, 시작 사이트 지정을 할 수 있습니다.
- 이미 실행 중일 때 다시 실행하면 새로 띄우지 않고 기존 창을 앞으로 가져옵니다.
- 설정 내보내기/가져오기로 사이트 목록과 알람 설정을 json 파일로 백업·복원할 수 있습니다.
- 볼륨/투명도 숫자를 클릭하면 직접 입력할 수 있습니다 (입력하는 즉시 반영, Esc로 취소)
- 알람 소리는 `alarm` 폴더의 mp3 파일명을 선택합니다 (기본 이름 `경험치업.mp3`, 없으면 시스템 소리로 대체)
- 설정은 exe와 같은 폴더의 `config.json`에 저장되며, 문제가 생기면 `error.log`를 확인하세요.
